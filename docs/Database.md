# Database

## Overview

Primary store is PostgreSQL. Queries are generated by **sqlc** from SQL files — never edit `internal/sqlc/*.go` by hand.

| Path | Purpose |
|------|---------|
| [`sql/schema/init.sql`](../sql/schema/init.sql) | Full DDL — all tables and indexes |
| [`sql/queries/`](../sql/queries/) | Named `.sql` queries consumed by sqlc |
| [`internal/sqlc/`](../internal/sqlc/) | Auto-generated Go query bindings |
| [`sqlc.yaml`](../sqlc.yaml) | sqlc configuration |

After modifying schema or queries:
```bash
sqlc generate
```

## Tables

| Table | Description | Key columns |
|-------|-------------|-------------|
| `users` | Registered accounts | `id`, `username`, `email`, `password_hash`, `two_fa_enabled` |
| `user_sessions` | Active JWT sessions | `user_id`, `session_id`, `expires_at` |

## sqlc workflow

```bash
# 1. Edit schema
vim sql/schema/init.sql

# 2. Add or modify named queries
vim sql/queries/<module>.sql

# 3. Regenerate Go bindings
sqlc generate

# 4. Use the generated types/functions
#    internal/sqlc/db.go      — DB handle
#    internal/sqlc/models.go  — struct types
#    internal/sqlc/*.sql.go   — query implementations
```

The `sqlc.yaml` file maps each query file to the `internal/sqlc` output package.
